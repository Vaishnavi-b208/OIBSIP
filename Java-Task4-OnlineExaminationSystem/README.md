# Online Examination System

## OIBSIP Java Development - Task 4

A GUI-based Online Examination System developed using Java Swing.

## Project Objective

The Online Examination System allows students to log in, update their profile, read examination instructions, answer multiple-choice questions, navigate between questions, and submit the examination.

The system also includes a countdown timer and automatically submits the exam when the time expires.

## Technologies Used

- Java
- Java Swing
- AWT
- Object-Oriented Programming

## Features

- Student Login
- Profile Update
- Password Update
- Examination Instructions
- Multiple Choice Questions
- Four options for each question
- Next and Previous navigation
- 10-minute countdown timer
- Automatic submission when time expires
- Manual exam submission
- Submission confirmation
- Result calculation
- Correct and incorrect answer count
- Time taken display
- Logout
- Exit confirmation
