# Number Guessing Game

## Java Development - Task 2

A colorful and interactive Number Guessing Game developed using Java Swing.

The player has to guess a randomly generated number within a limited number of attempts. The game provides hints such as Too High and Too Low and keeps track of the player's score and round history.

---

## Features

- Random number generation
- Easy, Medium and Hard difficulty levels
- Limited number of attempts
- Too High / Too Low hints
- Correct answer notification
- Hint button
- Score calculation
- Best score tracking
- Round history
- Timer
- Progress bar
- Play Again option
- Main Menu
- Game Over screen
- Input validation
- Enter key support
- Attractive Java Swing GUI

---

## Difficulty Levels

| Difficulty | Number Range | Attempts |
|------------|--------------|----------|
| Easy | 1 - 50 | 10 |
| Medium | 1 - 100 | 7 |
| Hard | 1 - 200 | 5 |
