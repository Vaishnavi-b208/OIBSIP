\# Java ATM Interface



\## Project Overview



The Java ATM Interface is a console-based ATM machine simulation developed using Java and Object-Oriented Programming concepts.



The application provides secure PIN authentication and allows users to perform common banking transactions such as withdrawal, deposit, transfer, and transaction history.



\## Aim



To develop a console-based ATM Interface that simulates basic banking operations using Java and Object-Oriented Programming.



\## Features



\- User ID and PIN authentication

\- Maximum 3 login attempts

\- Account balance checking

\- Cash withdrawal

\- Cash deposit

\- Money transfer

\- Transaction history

\- Insufficient balance validation

\- Transfer confirmation

\- Deposit and withdrawal receipts

\- Processing animation

\- Multiple bank accounts

\- Secure account information



\## Technologies Used



\- Java

\- Object-Oriented Programming

\- ArrayList

\- HashMap

\- Console-based interface



\## OOP Concepts Used



\### Encapsulation



Account information such as PIN, balance, account number and user details are kept private and accessed through methods.



\### Classes and Objects



The project contains multiple classes:



\- ATM

\- Account

\- Bank

\- Transaction

\- Main



\### Collections



\- ArrayList is used to store transaction history.

\- HashMap is used to store bank accounts.
